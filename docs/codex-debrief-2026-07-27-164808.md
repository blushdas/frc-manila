## Original Goal

## What Was Implemented
Created a dedicated `EventsCalendar` homepage section with the exact supplied
Luma calendar URL, a responsive dark frame with deliberate page margins, lazy
loading, accessible labelling, and a native "Event Calendar" heading treatment.
Inserted the section immediately after `Hero` and before `MerchPreview`. Added a
least-privilege CSP `frame-src` rule for Luma after browser testing exposed that
the site's `default-src 'self'` blocked the embed.

Deviations & Judgment:
- inference | Constrained the embed to the site's 7xl content width with responsive 20px/24px/48px gutters, then varied its height from 560px on phones to 720px on large desktops.
- inference | Set `color-scheme: dark` and matched the wrapper to Luma's dark surface so the third-party content blends into the site's black background.
- inference | Added a compact asymmetric header using the site's Koulen and Barlow Condensed typography to give the third-party calendar a native FRC Manila introduction.
- correction | The initially blank frame was not an in-app browser limitation. `proxy.ts` omitted `frame-src`, causing CSP `default-src 'self'` to block Luma. Adding `frame-src 'self' https://luma.com` made live events render on localhost.
- override | No `/handoff` files existed. The user explicitly instructed Codex to build directly, so the direct request became the implementation source.
